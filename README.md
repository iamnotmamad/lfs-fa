## دربارهٔ پروژه

این مخزن، **ترجمهٔ فارسی کتاب «لینوکس از صفر» (Linux From Scratch) نسخهٔ ۱۲.۴** است؛ کتابی که
قدم‌به‌قدم نشان می‌دهد چگونه یک سیستم لینوکسی را از کد منبع و بدون بسته‌های آماده، از پایه
بسازید. متن مرجع در [linuxfromscratch.org](https://www.linuxfromscratch.org/) منتشر شده و
این نسخه بر پایهٔ انتشار ۱ سپتامبر ۲۰۲۵ ساخته شده است.

متن این ترجمه **دستی** است و برای خواندن روان بازنویسی شده، نه خروجی ماشین ترجمه. در عوض،
همهٔ دستورها، نام بسته‌ها، مسیرها و بلوک‌های کد **مو‌به‌مو** مطابق نسخهٔ اصلی انگلیسی نگه
داشته شده‌اند تا آنچه اجرا می‌کنید با کتاب مرجع یکی باشد؛ فقط توضیح‌ها فارسی‌اند.

پوشش ترجمه کامل است: پیشگفتار، فصل‌های ۱ تا ۱۱ و پیوست‌های A تا F — از آماده‌سازی سیستم میزبان
و ساخت زنجیرهٔ ابزار متقابل تا نصب بسته‌های فصل ۸، پیکربندی سیستم، ساخت هسته و GRUB، بوت
نخستین و در پایان اختصارات، سپاس‌گزاری‌ها، وابستگی‌ها، اسکریپت‌های بوت، قواعد udev و مجوزها.

> کنترل کار در دست شماست؛ ما فقط کمک می‌کنیم سفرتان را آغاز کنید.
>
> — جرارد بیکمنز، از دیباچهٔ کتاب

> [!NOTE]
> این ترجمه **اثری رسمی از پروژهٔ LFS نیست**. نام و لوگوی LFS متعلق به پروژهٔ اصلی است و
> مسئولیت متن انگلیسی با همان پروژه است.

> [!WARNING]
> بخش بزرگی از دستورهای این کتاب با دسترسی ریشه (root) اجرا می‌شوند و می‌توانند کل سیستم
> میزبان را تغییر دهند. پیش از اجرای هر دستور، آن را کامل بخوانید و از داده‌های مهم پشتیبان بگیرید.

| فصل ۱ — مقدمه | چگونگی ساختن یک سیستم LFS، تازه‌های این نسخه، منابع و راه‌های کمک |
| فصل ۲ — آماده‌سازی سیستم میزبان | پیش‌نیازها، پارتیشن‌بندی، ساختن سیستم‌فایل، متغیر `$LFS` |

## شروع سریع

**۱. خواندن آنلاین** — ساده‌ترین راه: فایل
[`LFS-fa-manual.html`](LFS-fa-manual.html) را باز کنید. همه‌چیز درون همان یک فایل است.

**۲. دانلود و خواندن آفلاین** — مخزن را کلون کنید و فایل را در مرورگر باز کنید:

<div dir="ltr">

```bash
git clone https://github.com/iamnotmamad/LFS-12.4-Farsi.git
cd LFS-12.4-Farsi
xdg-open LFS-fa.html    # لینوکس
open LFS-fa.html        # macOS
start LFS-fa.html       # ویندوز
```

</div>

**۳. نسخهٔ چاپی** — [`LFS-fa-print.pdf`](LFS-fa-print.pdf) را باز کنید؛ یا روی فایل HTML
`Ctrl+P` بزنید تا همان صفحه‌بندی چاپی ساخته شود.

**۴. نسخهٔ قابل ویرایش** — [`LFS-fa-manual.docx`](LFS-fa-manual.docx) را در Word یا LibreOffice باز کنید.

## English

**Linux From Scratch 12.4 — Persian (Farsi) translation.** A hand-written, fully human Persian
translation of the LFS 12.4 book (released September 1, 2025). Commands, package names, paths and
all 685 code blocks are kept byte-for-byte identical to the English original; only the prose is
translated. The preface, chapters 1–11 and appendices A–F are complete.

Ships as a single offline HTML file (embedded Vazirmatn fonts and images, light/dark theme, copy
buttons on every code block), a print-ready PDF and an editable DOCX.

This is **not** an official LFS project. Book text: CC BY-NC-SA 2.0; computer instructions: MIT.
